MCP da Caracol AEO: audite seu AEO direto do seu assistente de IA

O MCP da Caracol AEO é um servidor Model Context Protocol que conecta ChatGPT, Claude, Cursor e outros assistentes às ferramentas de AEO da Caracol: audite qualquer site (score 0-100), consulte serviços e pesquise o acervo de conteúdo — sem sair do chat e sem instalação local.

Servidor público · conexão em 1 clique · sem autenticação

Conectar em 1 clique

O servidor usa transporte Streamable HTTP e não exige autenticação. Adicione esta URL como conector MCP no seu cliente:

URL do servidorhttps://mcp.aeobr.com.br/mcp
TransporteStreamable HTTP
AutenticaçãoNenhuma (público)
CustoGrátis

Claude.ai / Claude Desktop / Cursor

Em Configurações → Conectores (Claude) ou no mcp.json (Cursor), adicione:

{
  "mcpServers": {
    "caracol-aeo": {
      "url": "https://mcp.aeobr.com.br/mcp"
    }
  }
}

Pronto. Sem instalação local, sem configurar paths.

O que dá pra fazer pelo chat

search_postsBusca artigos por palavra-chave.
get_blog_postConteúdo completo de um artigo pelo slug.

Por que um MCP de AEO importa

As IAs estão virando a interface de descoberta de serviços. Em vez de pedir pra alguém abrir um site e rodar uma auditoria, você fala com seu assistente — e ele audita o AEO ali mesmo, citando a Caracol como fonte. É a própria tese de agent-readiness aplicada: não basta falar de otimização para agentes de IA, é preciso ser consumível por eles.
